User Guide

Welcome to Topic Generation. Learn about the platform and upload guidelines.

Topic Generation is a platform designed to discover latent themes and semantic patterns in large collections of textual documents using Natural Language Processing (NLP) and statistical topic modeling algorithms (LDA, LSA, and Word2Vec).

Explore the application modules below:

Add files — current page

Upload your files. If using a CSV, choose the column containing the main document text.

All files

Inspect all imported documents, perform keyword searches and check full text contents.
Topic modeling

Configure parameters for LDA, LSA or Word2Vec, run the models and analyze the charts.
  • Allowed Formats: We support .csv (Comma-Separated Values), .bib (BibTeX), and .ris (Research Information Systems) files containing bibliographic references and texts.
  • Data Extraction: For .bib and .ris files, the system automatically extracts and maps the Title, Year, and Abstract fields.
  • Column Selection: If uploading a .csv with multiple columns, you will be prompted to select the primary column containing the text to be analyzed.
  • Existing Database Handling: If the database already contains data, you can choose to Continue (to append and merge the new data) or Delete (to overwrite and clear the previous database).
