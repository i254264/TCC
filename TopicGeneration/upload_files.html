Upload & File Management Guide

Welcome to Topic Generation! Here is a quick guide on how to navigate this tool and manage your dataset uploads:

Sections Overview

  • Add files: This screen! Upload your textual datasets or bibliographic records to load them into the system.
  • All files: View, search, and explore all records currently loaded into the active database.
  • Topic modeling: Configure, train, and visualize NLP algorithms (LDA, LSA, Word2Vec) using the uploaded abstracts.

Upload Rules & Guidelines

  • Allowed Formats: We support .csv (Comma-Separated Values), .bib (BibTeX), and .ris (Research Information Systems) files.
  • Data Extraction: For .bib and .ris files, the system automatically extracts and maps the Title, Year, and Abstract fields.
  • Column Selection: If uploading a .csv with multiple columns, you will be prompted to select the primary column containing the text to be analyzed.
  • Existing Database Handling: If the database already contains data, you can choose to Continue (to append and merge the new data) or Delete (to overwrite and clear the previous database).
